# 0001: Astro の静的サイトを GitHub Pages で公開する

- 日付: 2026-11-06
- 状態: 採用

## 背景

ポートフォリオサイトを一人で長期運用したい。サーバー管理の手間は最小にし、AI と一緒に保守できる構成にしたい。

## 決定

- Astro の静的出力（SSR なし）で作る
- ホスティングは GitHub Pages、デプロイは GitHub Actions の公式 `withastro/action`
- コンテンツは Markdown と Content Collections で管理する

## 理由

- 静的サイトなのでサーバー・DB の保守が不要
- Markdown 管理なので、AI に記事追加や構成変更を頼みやすい
- GitHub 上で Issue / PR / CI が完結し、運用の練習になる

## 見送った案

- Next.js + Vercel: 機能は多いが、ポートフォリオには過剰で更新追従のコストが高い
- レンタルサーバー + 手動アップロード: 経験済みで学びが少なく、自動化しにくい

## 見直す条件

- 認証付きページや動的機能が必要になったら（例: 非公開のナレッジベース）、Cloudflare Pages などへの移行を検討する
